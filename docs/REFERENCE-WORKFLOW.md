# 参考片工作流与执行规则

根据用户提供的拆解资料提炼方法，不把二手报告的统计、模型推荐或其他应用能力当作已验证事实，也不发布资料包和原片。

1. 主题只保留一个核心机制：具体问题、可判断的例子、机制发生、结果回扣。按题材与时长重新设计结构，不固定每片镜头数或照搬示例故事。
2. 风格语言提取配色、材质、光影、文字层级、字幕安全区、运动与转场；每镜仍重新编写解释当前知识的动画。
3. 先设计建立、变化、结果三个关键状态，再编写确定性 `draw(t)`。几何与数据先算后画，少量可读单元优先于密集关系网。
4. 从真实渲染帧测量文字边界、字号、内容区与主体运动；把实际帧及报告交给所选视觉模型返修。通过自动检查不能保证完整审美或科学正确性。
5. 配乐只有从用户上传音频获得可靠节拍时才对齐；没有原音频时不声称完成参考片节拍分析。配音按用户开关保留，不强制套用报告的无旁白形式。
6. 逐镜按编号执行，可选起止范围，保留不在范围内的成果。原视频任务优先查询、下载，避免重复付费。

Hypit 的 README 展示了参考视频转为包含素材、字幕、效果的可重跑 SVML 工作流，也能从零开始设计。其运行环境与本网站的隔离 Canvas / Cloudflare Worker 不同；其修改版 Apache 许可对多租户 SaaS 有额外条件，本次没有引入其源码或依赖。

继续精细拆解时，3–5 条同类原片已足够起步，优先选不同主题但风格接近的完整片段，并注明最看重的动画、构图或节奏。原片用于分析，不上传公开源码仓库。
