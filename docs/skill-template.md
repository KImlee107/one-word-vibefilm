# 用户偏好导出为 skill 的模板

本模板用于整理用户明确希望复用的创作习惯。它保存规则、范围和示例，不训练模型，也不替代视频渲染引擎。一次片段修改默认只作用于本项目；用户希望长期沿用时，才归入导出的偏好。

将以下主体保存为目标 Agent 支持的 SKILL.md。替换 {{占位内容}}，删除未填写项和示例；不要把 API 密钥、个人素材文件内容或未获授权的音色放进 skill。

## 使用顺序

1. 以当前会话中用户明确给出的要求为准；本 skill 提供可覆盖的默认值。
2. 将主题整理成受众、核心问题、前提、可视化机制、旁白和分镜。
3. 核实数字、公式、事实与素材来源；保存事实清单。
4. 使用项目已支持的预览和渲染方法，先显示可预览的场景。
5. 修改单个片段时保留其他片段，说明字幕、时长或配音是否需要同步调整。
6. 交付时注明实际生成的文件、格式、时长、验证结果和仍不可用的功能。

## 内容质量

- 数学和数据动画采用明确前提，公式、字幕、旁白相互一致。
- 区分理论结果、模拟数据与示意画面。
- 保留来源链接；事实未核实则标明待核实，不填充虚构来源。
- 屏幕文字作为独立可编辑层；配音变长时重新检查字幕与镜头时序。
- 对已完成场景进行版本记录，支持比较和恢复。

## 能力与操作边界

- 本 skill 不添加账号、模型权限或服务额度，不自动连接付费平台。
- 只有实现并配置过的模型能力才可调用；本地规则修改不能冒充任意语义重写。
- 不从参考 skill 继承固定配乐、固定发布渠道、桌面路径或特定模型要求。
- 发布、上传和付费调用遵循用户在当前任务中的授权及工具权限；本模板本身不授予这些操作权限。
- 成本和预计用时标明依据；没有测量或服务报价时显示目标或估算。

## 导出建议

导出内容应只包含可携带的文字规则和项目引用。删除空字段，保留用户实际修改的原话，给出版本号。风格预览图、音乐与音色文件若另行分享，应单独记录来源与使用范围。

如需升级成执行型 skill，可再附与当前引擎匹配的脚本和示例项目；在实际验证之前，把它标为「偏好模板」，不宣称安装后就能自动制作所有视频。
