# 本地音乐节奏分析与轻量卡点

网站可以对用户主动上传的 BGM 在浏览器内分析。`analyzeMusicFile(blob)` 使用 Web Audio 解码，`analyzeAudioBuffer(buffer)` 分析采样数据；不上传音频，不调用模型，不改写原音轨，也不生成媒体文件。

返回数据为 `{duration,bpm,confidence,beats,sections,method,reliable,warnings}`。`beats` 是检测到的起音时刻（秒），并非按默认 BPM 编造的等距网格。`sections` 是基于音量能量变化的粗略段落，不等于专业音乐结构识别。时间采样约为 20 毫秒。

算法将音频缩采样用于分析，以低频能量上升沿为主、全频起音为辅，再通过自相关与真实峰值的周期一致性估计 60–180 BPM。半速、倍速、切分节奏、变速、弱打击乐和人声可能造成歧义。`confidence >= 0.6` 且检测到至少四个稳定起音时才将 `reliable` 设为 true；静音、持续长音和不稳定节奏返回空拍点，不强行给出可用 BPM。

`snapCompositionToBeats(comp,sceneStart,sceneDuration,analysis)` 返回新的绘图数据。仅在可信分析下，将距离实际检测拍点不超过 0.18 秒的对象出入场和关键帧时间轻量吸附。它不会移动整个镜头边界、改写动画数值、拉长视频、改变公式或强迫粒子背景卡点；若吸附会使事件结束早于开始或过短，保留原事件时序。站内 BGM 默认循环，因此超过单曲时长时重复其已检测拍点。

字幕仍按现有镜头/旁白规则显示，当前不是逐字强制对齐。配乐拍点也不能保证旁白语义自然落在音乐强拍上；重要数字、结论和图形推演应试听后复核。检测无节律时保留原动画是正常结果，不应展示伪造的成功状态。

本模块不是人声伴奏分离器。包含旁白的参考视频音轨，不能直接宣称已获得干净 BGM。本次未把用户上传的视频、抽帧或音轨写入公开网站；用户需选择自己要用于成片的音乐文件。

测试使用内存中的合成采样数组验证 120 BPM、90 BPM、静音、长音、事件边界和解码清理；没有写出 WAV、MP3 或视频。
