# one-word-vibefilm

## 见知 · Vibe Studio

一个可逐镜预览、修改和导出的知识视频网站。用户自行配置模型 API 后生成内容。本次交付不包含预生成视频，也没有调用付费模型。

## 在网站使用

1. 点击左侧「模型接口」，只需填写 DeepSeek API Key 和 MiniMax API Key。网站已固定预设 DeepSeek V4.1 Flash（官方调用 ID `deepseek-flash`）、MiniMax `speech-2.8-hd` 和 `MiniMax-H3`，接口地址和协议自动配置；MiniMax 的同一个 Key 同时用于配音和视频。
2. 输入主题，选择时长、画幅、风格和制作方式，点击「生成分镜与代码画面」。第一阶段编排分镜；第二阶段按已接入的 [vibe-knowledge-film](https://github.com/HeyChengC/vibe-knowledge-film) 为每镜现写 JavaScript 动画代码，实际渲染三个时刻，再默认进行两轮看图返修。网站不再把少数固定图形替换文字后当作成片。
3. 分镜解析兼容包装层、镜头数组、中英文常见字段及时间范围，不再只接受单一字段格式。格式仍不完整时最多追加1次明确显示的整理请求；失败可下载已脱敏的返回内容，不自动循环重试。
4. 每完成一镜即可预览。进度显示真实阶段、成功镜头数、失败和用时；等待模型时不伪造百分比。取消会保留已完成镜头，失败镜头可单独重试。语义修改会重绘当前镜头，其他镜头不重做。
5. 配音与 AI 视频镜头分别按需调用，旁白可只重做选中镜头或补齐缺失部分。AI/混合模式可明确选择一批镜头交给 H3，逐镜查询真实任务状态；代码预览不冒充 AI 视频。H3 每次支持 4–15 秒短片。
6. 可选上传自己的配乐，或使用网站在播放/导出时合成的原创氛围音乐。字幕、配音、配乐均可切换。
7. 在最新版桌面 Chrome / Edge 导出。支持 AVC 编码时为 MP4，其他支持的编码环境回退 WebM；浏览器不支持编码时会提示。未完成的绘图不会静默替换成通用模板后导出。没有配音素材时，不会凭空生成旁白。

常见预设：15、30、45、60、90、120、180、300 秒；9:16、16:9、1:1、4:5、3:4、4:3、21:9；黑金叙事、纸上实验、霓虹科技、工程蓝图、杂志信息图、宇宙深空、柔彩手绘、极简白。7 种画幅均用于实际预览与导出。H3 的 4:5 视频素材会由其原生支持的 3:4 裁切，界面会在提交前说明。

初始画面是可交互示意，不代表已经调用模型或生成成片。配音的收费和视频任务收费由对应服务商计算。连接测试尽量使用非生成请求，不表示余额、地区或具体模型权限全部通过。停止等待不会保证取消服务商已经提交的任务。

## 密钥与保存

密钥只保存在当前页面内存，并通过同源 HTTPS API 代理转发给指定服务商；服务端不保存密钥，不写入项目、源码、日志或浏览器持久存储。刷新页面后需重新填写。项目 JSON 保存文字、参数、分镜与偏好，不保存 API Key 或二进制音视频；请另外下载重要生成素材。

本站已按所有者要求设为公开，任何拥有链接的人都可访问。每位使用者填写自己的 Key，网站没有共享密钥；其他访问者不会得到你的 Key、分镜或本机保存的项目。请求代理限制服务商域名，详见 [API 接口说明](docs/API.md)。

## 本地开发与部署

需要 Node.js 20+。运行时依赖为浏览器媒体封装库 Mediabunny 与动画语法解析器 Acorn；开发依赖包含 esbuild 和用于静帧测试的 @napi-rs/canvas。

```sh
npm ci
npm run check
npm test
npm run build
```

构建产物 `dist/server/index.js` 是 Cloudflare Worker ES Module，内含网页资源与 `/api/*` 接口。项目按 Sites 托管约定保存 `.openai/hosting.json`，也可将同一 Worker 部署到兼容环境。本地直接打开 HTML 只能查看前端；API 需要 Worker 后端。建议使用 Wrangler 等 Worker 开发环境运行后端。

## 实现与验证边界

- 新创作使用上游 `VK` 引擎和每镜独立 JavaScript 函数；代码只在无同源权限的 iframe 内的可终止 Worker 执行，不在应用主页面执行。语法检查、CSP与运行隔离共同限制代码。旧 JSON composition 仅用于项目兼容与内置示意。详见 [实际 skill 接入](docs/VIBE_FILM.md)。
- 忽略标签文字后比较绘图结构与运动指纹，拒绝完全相同的画面仅换标题。允许对象母题延续，但数学数据、几何或推演状态应真实改变。质量校验是有界检查，不等于已人工验证每次模型创作。
- 默认每镜1次代码生成加2次视觉返修请求（可选0/1轮），费用由你使用的 DeepSeek 服务计费；失败不会暗中无限重试。画面就绪、配音、AI 镜头和视频导出分别展示真实状态。
- 保留源项目、字幕与每镜版本，有效降低局部修改的重复生成成本。
- 当前通过请求模拟验证 API 协议、参数校验、密钥脱敏和错误处理，并通过 Node Canvas 运行上游引擎与网页 Worker 桥接器检查动画；未使用真实用户密钥调用服务。
- 本环境没有可用的共享浏览器控制工具，网页浏览器交互和浏览器视频编码尚待实际设备验证；本轮未生成音视频。
